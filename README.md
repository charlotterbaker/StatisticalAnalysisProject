# Analyzing The Impact and Recovery of Global Cybersecurity Threats (2015–2024)

## Dataset Overview
This project utilizes the dataset titled **Global Cybersecurity Threats (2015–2024)**, which consists of 3,000 documented cybersecurity incidents across various countries and sectors. The dataset includes variables such as type of attack, affected industry, country of occurrence, financial damage (in millions of USD), recovery time, and the number of affected users.

**Source:** *Kaggle–GlobalCybersecurityThreatsDataset: https://www.kaggle.com/datasets/atharvasoundankar/global-cybersecurity-threats-2015-2024?resource=download*

## Objective
This project evaluates how variables such as attack type, industry sector, and recovery time relate to financial loss. Using this real-world cybersecurity incident data from 2015–2024, the analysis looks to identify whether any patterns or relationships exist between these characteristics and the extent of economic damage, and whether they can be meaningfully modeled using traditional statistical methods.

## Testing Performed:
- **Exploratory Data Analysis:** Understanding relationships between variables and financial loss with summary statistics and visualizations.
- **One-way ANOVA:** Evaluating the type of cyberattack's affect on financial loss incurred.
- **Multiple Linear Regression:** Testing the relationship between industry sector and financial loss.
- **Chi-square Test of Independence:** Looking at the association between attack type and industry sector.
